# Twitch Glitch

Unmodified copies of the flat Glitch logo from Twitch's official brand kit
(https://brand.twitch.com, `Twitch-Brand.zip`, Logo Usage Guidelines v3.0). Twitch and Glitch are
trademarks of Twitch Interactive, Inc. and aren't covered by this repo's license.

Follow the kit's rules: don't stretch, rotate, recolour or add effects; use only core-palette
colours with enough contrast; keep clear space around it.
